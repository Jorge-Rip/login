⛔ Acesso Negado (HTTP 401 Não Autorizado)

Você tentou acessar diretamente esta página restrita sem fornecer um Token JWT válido no cabeçalho Authorization: Bearer.

Explicação Pedagógica: Por que o acesso foi bloqueado?
  • Rota Protegida por Token: Os dados confidenciais desta página são protegidos pelo endpoint FastAPI GET /api/dados-restritos com a dependência Depends(get_current_user).
  • Tentativa de Acesso Direto: Ao digitar o link diretamente no navegador ou sem efetuar login prévio, o navegador não possui o token de sessão ou o cabeçalho Authorization não foi injetado.
  • Segurança contra Invasão: O backend FastAPI interceptou a requisição e devolveu o código HTTP 401 Unauthorized impedindo o vazamento de informações.
